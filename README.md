# 🦊 Rubah (Ruang Baca Harian)

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![Language: Rust](https://img.shields.io/badge/Language-Rust-orange.svg)](https://www.rust-lang.org/)

**Rubah** (Ruang Baca Harian) adalah aplikasi pembaca RSS & Atom Feed berbasis Terminal User Interface (TUI) untuk Linux, macOS, dan Windows.

---

## 💻 Instalasi

### 🐧 Linux / 🍎 macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/WhaTheFoxSay/rubah/main/install.sh | bash
```

### 🪟 Windows (PowerShell):
```powershell
irm https://raw.githubusercontent.com/WhaTheFoxSay/rubah/main/install.ps1 | iex
```

---

## 🚀 Cara Menjalankan

Jalankan perintah berikut di terminal:
```bash
baca
```

---

## 📋 Fitur Utama

- **TUI 3 Panel**: Tampilan terpisah untuk Kategori/Channel, Daftar Berita, dan Reader.
- **Dukungan Multibahasa**: Pilihan 6 bahasa (Inggris, Indonesia, Jepang, Belanda, Spanyol, Arab).
- **Pembaca Konten & Foto**: Membaca artikel penuh dan menampilkan gambar berita di terminal.
- **Pencarian Realtime**: Filter artikel berdasarkan kata kunci.
- **Bookmark & Kategori**: Menyimpan artikel favorit dan mengelompokkan channel feed.

## ⌨️ Shortcut Keyboard

| Shortcut | Fungsi |
| :--- | :--- |
| `Tab` / `Shift+Tab` | Pindah panel |
| `j` / `k` atau `↓` / `↑` | Navigasi item |
| `Enter` / `Space` | Ekspansi Kategori / Baca artikel |
| `f` | Mode Layar Penuh (Reader) |
| `l` | Ganti Bahasa |
| `i` | Tampilkan / Sembunyikan Foto |
| `b` | Simpan / Hapus Bookmark |
| `o` | Buka link di Browser |
| `m` | Pindahkan Feed ke Kategori |
| `Shift + C` | Hapus Kategori |
| `Shift + D` | Hapus Feed |
| `a` | Tambah Feed Baru |
| `r` | Refresh Feed |
| `/` | Pencarian |
| `Esc` | Kembali / Reset |
| `1` / `2` | Tab All Feeds / Bookmarks |
| `?` | Bantuan Shortcut |
| `q` | Keluar |
